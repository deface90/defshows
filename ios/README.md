# defShows для iPhone

Нативный клиент на SwiftUI для iOS 17+. Без сторонних зависимостей.
Первый сценарий: вход по email/паролю, коллекция с поиском по названию,
сезоны и серии, отметка и отмена просмотра, выход с отзывом refresh-токена.
Приложение подключается к `https://shows.deface.dev/api`; ввод сервера не нужен.
Токены сохраняются в Keychain; при HTTP 401
клиент обновляет токены и повторяет запрос один раз.

## Запуск на Mac

1. Установи Xcode с поддержкой iOS 17 или новее и открой `DefShows.xcodeproj`.
2. Для симулятора выбери iPhone в списке устройств и нажми Run (⌘R).
3. Для своего iPhone: в Xcode → Settings → Accounts добавь Apple Account.
   В target DefShows → Signing & Capabilities выбери свою Personal Team.
   Если стандартный Bundle Identifier недоступен, замени `com.defshows.ios`
   на уникальный, например `com.yourname.defshows`.
4. Подключи iPhone, включи Developer Mode, если Xcode предложит,
   выбери телефон в списке устройств и нажми Run.
5. Войди существующим email и паролем от shows.deface.dev.
   Социальный вход, регистрация и сброс
   пароля в этой версии не реализованы. Для аккаунта только с OAuth сначала
   настрой пароль через веб-версию, если она это позволяет.

Разрабатывать и запускать на личном устройстве можно с бесплатной Personal Team.
Платная подписка нужна позже для TestFlight / App Store.

## Проверка сборки

На Mac из корня репозитория:

```sh
xcodebuild -project ios/DefShows.xcodeproj -scheme DefShows \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/defshows-ios-build CODE_SIGNING_ALLOWED=NO build
```

Ручная проверка на тестовом аккаунте:

- Войти с неверным паролем: видна ошибка, можно повторить вход.
- Войти с верным паролем: список совпадает с веб-версией.
- Открыть сериал, отметить серию, проверить отметку в веб-версии, отменить её.
- Вернуться в коллекцию: прогресс обновляется; потянуть список вниз для обновления.
- Перезапустить приложение: сессия восстанавливается из Keychain.
- После истечения access-токена обновить список: сессия продлевается автоматически.
- Отключить сеть: появляется ошибка, отметка серии не меняется без подтверждения.
- Выйти и перезапустить: снова виден экран входа. Для отзыва сессии нужна сеть.

## Границы первой версии

Добавление сериалов, OAuth, настройки и уведомления пока доступны в веб-версии.
Клиент требует подключения к серверу; офлайн-кэш не реализован.
Перед App Store ещё нужны иконка, материалы публикации и проверка требований магазина.

В Linux-среде разработки нет Xcode / iOS SDK: сборку и поведение на устройстве
необходимо проверить на Mac командой выше. Backend и его контракты не менялись.
